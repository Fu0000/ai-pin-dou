## 0. 设计哲学

> **微信「轻应用」+「8-bit 像素美学」+「情绪温度」**

### 三条铁律
1. **一页一任务**：每个页面只有一个主操作，禁止折叠菜单和弹窗广告
2. **像素灵魂**：核心视觉元素（图标、装饰、动效）保留像素风格
3. **温度感**：色彩偏暖、文案有"人情味"，避免冷冰冰的工业风

### 6.2 图纸预览页设计要点（最关键页，单独说明）

> 这是用户决定"下不下单"的核心页面，设计权重最高

必须一屏可见以下信息：
1. **像素图纸预览**（占主视觉，可缩放）
2. **实物尺寸卡片**（"成品约 24cm × 24cm，约 A4 大小"+ 对比图）
3. **难度提示**（"预计耗时 2 小时"）
4. **颜色清单**（前 5 个色号 + 库存灯，可展开看全部）
5. **底部固定栏**（价格 + "一键加购"主按钮）

可选项：
- 切换难度档（不重新跳转）
- 单格修改入口
- 重新生成入口

## 7. 动效与交互规范

### 7.1 标准时长

| 类型 | 时长 | 缓动 |
|---|---|---|
| 页面切换 | 300ms | ease-in-out |
| 弹窗出现 | 200ms | ease-out |
| 按钮反馈 | 100ms | ease-in |
| 像素生成动画 | 800ms | linear（像素逐格显示）|

### 7.2 触摸反馈
- 所有可点击元素必须有 hover/active 状态
- 主按钮按下时缩放至 0.96，配合阴影变化

### 7.3 像素风专属动效（点睛之笔）

- 加载等待：8-bit 像素旋转方块
- 成功提示：像素风★星迸发
- 完成生成：像素逐格显现（参考小霸王游戏开机动画）

## 8. 文案规范

### 8.1 语气

- **温度感**：用"你"不用"您"，避免过度正式
- **行动指引**：用动词开头（如"上传你的照片"而非"图片上传"）
- **情绪共鸣**：紧扣"亲手做、独一无二、送给重要的人"

### 8.2 错误文案模板

❌ 不要：`系统错误，请稍后重试`  
✅ 要：`图纸生成失败了，要不再试一次？`（友好 + 给出 action）

### 8.3 关键场景文案库

| 场景 | 文案 |
|---|---|
| 首次进入 | "把你的照片，变成可以触摸的礼物 →" |
| 上传中 | "图片上传中…" |
| 生成中 | "AI 正在为你设计专属图纸（约 8 秒）" |
| 生成成功 | "你的专属图纸来啦！" |
| 缺货替换 | "X 个色号缺货，已为你换成相近色" |
| 安全弹窗 | "拼豆需要熨烫定型，请大人陪同操作哦" |
