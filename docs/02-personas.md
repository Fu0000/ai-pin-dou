## 2. P1 · 「小红书晒图族」小薇 ⭐主目标

### 2.1 基础信息
| 项 | 内容 |
|---|---|
| 年龄 | 22~28 岁 |
| 性别 | 女 |
| 城市 | 一线 / 新一线 |
| 职业 | 互联网公司白领 / 应届毕业生 / 自由职业 |
| 月可支配收入 | 2000~5000 元 |
| 常用 App | 小红书（重度）、微信、抖音、淘宝 |

### 2.2 行为画像
- 每天刷小红书 ≥ 1 小时，喜欢「沉浸式」「治愈系」「ootd」内容
- 周末偏好"低门槛、出片率高"的休闲方式
- 对手作类目消费意愿强，但**没耐心做太复杂的**（≤ 3 小时）
- 朋友圈/小红书晒图欲极强，是平台天然传播节点

### 2.3 核心需求与痛点

| 需求 | 痛点 | 产品如何回应 |
|---|---|---|
| 把自拍/宠物照变成有质感的小礼物 | 不会做，市面上的标品没有"我"的元素 | C2M 个人照片定制（关联 ADR-001） |
| 出图必须好看，发小红书有面子 | 自己拼的丑、不像 | 算法精度要够 + 三档难度让她选简单档 |
| 不想被催促，享受过程 | 现有教程长、节奏快 | 一页一任务 + 心流导向的 UX |
| 价格不能太离谱 | 标品 30 元，定制不能贵到 200+ | 客单价锚定 50~100 元（关联 ADR-008） |

### 2.4 用户原话
> *"看小红书上有人做自家猫的拼豆，超想试一下，但搜了半天不知道要买什么颜色多少颗。"*  
> *"我做手工就图个解压，太复杂的我会直接放弃。"*

### 2.5 关键决策点
- **进入路径**：小红书 KOL 笔记 → 评论区 → 小程序
- **最关心**：成品好看 + 操作简单 + 客单价 ≤ 100 元
- **流失点**：算法生成图丑 / 实物太大或太小 / 操作步骤超过 5 步

## 3. P2 · 「亲子手作宝妈」李姐

### 3.1 基础信息
| 项 | 内容 |
|---|---|
| 年龄 | 30~38 岁 |
| 性别 | 女 |
| 家庭 | 已婚，有 1 个 5~10 岁孩子 |
| 城市 | 一线~三线均有 |
| 月可支配收入 | 5000~15000 元（家庭决策权） |
| 常用 App | 微信（重度）、小红书、抖音、家校群 |

### 3.2 行为画像
- 周末为孩子寻找"有教育意义的手作活动"
- 决策时**先关心安全**，再关心教育价值，最后关心价格
- 容易成为"妈妈群口碑传播节点"
- 在意作品的"成就感"，喜欢和孩子一起做并展示

### 3.3 核心需求与痛点

| 需求 | 痛点 | 产品如何回应 |
|---|---|---|
| 安全可靠的手作材料 | 担心三无产品有毒 | SGS 认证强制准入（关联 guihua.md §八） |
| 教孩子专注力 / 色彩认知 | 一般手作复杂度不可控 | 简单档（≤ 8 色）适合儿童 |
| 熨烫环节风险高 | 怕孩子被烫伤 | 安全提示弹窗 + 监护警示 |
| 作品要能展示给老师 / 朋友圈 | 标品图案孩子不感兴趣 | 用孩子的画/照片定制 |

### 3.4 用户原话
> *"做拼豆挺好的，但是熨斗那一步我都不敢让孩子靠近。"*  
> *"我就怕买的豆子是三无的，那种塑料烫了味道大。"*

### 3.5 关键决策点
- **进入路径**：妈妈群推荐 / 家校老师推荐 / 微信公众号
- **最关心**：安全 > 教育 > 趣味 > 价格
- **流失点**：没有看到 SGS 标识 / 安全警示不足 / 无法和孩子共同操作

## 4. P3 · 「硬核创作者」阿杰

### 4.1 基础信息
| 项 | 内容 |
|---|---|
| 年龄 | 18~30 岁 |
| 性别 | 男女均有，男性略多 |
| 身份 | 在校大学生 / 自由职业者 / 退休 / 宝妈兼职 |
| 时间富裕度 | 高（每天可投入 ≥ 2 小时） |
| 收入诉求 | 副业增收 500~3000 元/月 |

### 4.2 行为画像
- 已经是拼豆爱好者，会在小红书/B站发自己的作品
- 拼图技术 ≥ 1 年经验，能完成大尺寸（48×48 以上）
- 想从爱好变现，但没渠道
- 对图纸版权、稀有色号、专业工具有强烈兴趣

### 4.3 核心需求与痛点

| 需求 | 痛点 | 产品如何回应 |
|---|---|---|
| 技术变现 | 在闲鱼接单不安全、维权难 | 平台担保的代拼撮合（关联 ADR-006） |
| 稳定的图纸销售渠道 | 自己作品难以被发现 | UGC 社区 + 创作者激励（Phase 2） |
| 稀有色号收集 | 商城从来不卖 | PX 积分兑换非卖品（关联 ADR-007） |
| 创作身份认同 | 没有徽章/等级体现资历 | 多级徽章 + 大师认证 |

### 4.4 用户原话
> *"我在小红书有几千粉丝，私信问我接不接代拼的特别多，但单独走支付宝转账太麻烦也不安全。"*  
> *"想要那种限量金属色，淘宝从来没卖过。"*

### 4.5 关键决策点
- **进入路径**：B 站/小红书内容 + 平台主动招募
- **最关心**：作品曝光 + 稳定佣金 + 身份认同
- **流失点**：抽佣比例太高（> 20%）/ 平台流量不公平 / 稀有色号永远抢不到

## 5. P4 · 「礼物急需者」周先生（长尾用户）

### 5.1 基础信息
| 项 | 内容 |
|---|---|
| 年龄 | 25~40 岁 |
| 性别 | 男（占多） |
| 场景 | 临近女友/老婆生日/纪念日 |
| 价格敏感度 | 极低（"贵点没事" |
| 时间敏感度 | 极高（"明天就要"） |

### 5.2 核心需求
- **不想自己做**，要现成成品
- **必须独一无二**（情侣合照定制）
- **包装必须够档次**（送礼用）

### 5.3 产品如何回应
- 代拼撮合（Phase 1 末加分项）
- 高端礼盒套餐（关联 project-plan.md 礼品化闭环）
- 节日营销日历（情人节/纪念日打头阵）

### 5.4 用户原话
> *"明天结婚纪念日了，能不能帮我把结婚照做成拼豆？包装要好的。"*

## 6. P5 · 「线下店主」王老板（B 端 / Phase 2）

### 6.1 基础信息
| 项 | 内容 |
|---|---|
| 经营 | 商场内手作体验店 |
| 拼豆品类占比 | ≥ 60% 营收 |
| 痛点 | 新手顾客频繁问颜色和位置，店员陪同成本高 |
| 月营收 | 3~10 万 |

### 6.2 核心需求
- 引流到店 + 减轻店员陪同负担
- 顾客自助生成图纸 + 自动配料
- 客流转化为长期复购（线下→线上）

### 6.3 产品如何回应
- 线下 SaaS（Phase 2 W9）
- 商家端图纸生成器
- 顾客扫码即落入私域

## 8. 决策时的"问 Persona"工具

每次产品决策时，问自己：

> 「这个改动会让 **P1 小薇** 更愿意完成下单吗？」  
> 「这个改动会让 **P2 李姐** 更放心地让孩子参与吗？」  
> 「这个改动会让 **P3 阿杰** 更有动力持续创作吗？」

如果三个答案都是"无所谓"，那这个改动可能不值得做。
