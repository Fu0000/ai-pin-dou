## 0. 文档说明

> 用户画像不是凭空想象的"理想用户"，而是基于 `guihua.md` 的市场数据 + 用户原话提炼的**典型代表**。  
> 每个 Persona 都应该能在产品决策时被引用：「这个改动对 P1 友好吗？P3 会不会被劝退？」

**MVP 仅聚焦 P1 小薇（小红书晒图族），P2~P5 作为兼容画像保留**（关联 ADR-012）。  
v0.5 起，所有产品决策的反查命题统一以 P1 为主体，不再在 P1/P2/P3 之间多目标对冲。P2~P5 的 JTBD 仅作为「不要主动做坏」的兼容性约束，不作为新功能立项依据。

## 2. P1 · 「小红书晒图族」小薇 ⭐主目标

### 2.1 基础信息
| 项 | 内容 |
|---|---|
| 年龄 | 22~28 岁 |
| 性别 | 女 |
| 城市 | 一线 / 新一线 |
| 职业 | 互联网公司白领 / 应届毕业生 / 自由职业 |
| 月可支配收入 | 2000~5000 元 |
| 常用 App | 小红书（重度）、微信、抖音、淘宝 |

### 2.2 JTBD 完整映射 ⭐

| JTBD 字段 | 内容 |
|---|---|
| Job Statement | 当我刷到萌宠拼豆笔记，我想把我家猫做成同款，以便发图收赞 |
| Functional Job | 把我自己拍的照片转成可寄到家的拼豆图纸 + 配料 |
| Emotional Job | 想要"我也能做出来"的成就感与治愈感 |
| Social Job | 在小红书晒图时显得手巧、有审美 |
| Hire Trigger | 看到 KOL 笔记 + 周末 + 想要拍照可发的小成就 |
| Fire Trigger | 算法生成图片粗糙、客单价 > 100 元、操作 > 5 步 |

> 字段长度统一控制在 ≤ 60 字。Hire / Fire Trigger 用于运营和风险评审时反查"我们正在加 / 砍的是哪类触发器"。

### 2.3 行为画像
- 每天刷小红书 ≥ 1 小时，喜欢「沉浸式」「治愈系」「ootd」内容
- 周末偏好"低门槛、出片率高"的休闲方式
- 对手作类目消费意愿强，但**没耐心做太复杂的**（≤ 3 小时）
- 朋友圈/小红书晒图欲极强，是平台天然传播节点

### 2.4 核心需求与痛点

| 需求 | 痛点 | 产品如何回应 |
|---|---|---|
| 把自拍/宠物照变成有质感的小礼物 | 不会做，市面上的标品没有"我"的元素 | C2M 个人照片定制（关联 ADR-001） |
| 出图必须好看，发小红书有面子 | 自己拼的丑、不像 | 算法精度 + AI 风格变体 3 套（关联 ADR-019） |
| 不想被催促，享受过程 | 现有教程长、节奏快 | 一页一任务 + M13 心流陪伴模式（关联 ADR-021） |
| 价格不能太离谱 | 标品 30 元，定制不能贵到 200+ | 客单价锚定 50~100 元（关联 ADR-008） |

> P1 段落本无 PX 钩子（PX 钩子集中在 P3）。MVP 复购钩走「首单大礼包 + 老用户 9 折 + 包裹内『下次免运费』券」（关联 ADR-018, ADR-020）。

### 2.5 用户原话
> *"看小红书上有人做自家猫的拼豆，超想试一下，但搜了半天不知道要买什么颜色多少颗。"*  
> *"我做手工就图个解压，太复杂的我会直接放弃。"*

### 2.6 关键决策点
- **进入路径**：小红书 KOL 笔记 → 评论区 → 小程序
- **最关心**：成品好看 + 操作简单 + 客单价 ≤ 100 元
- **流失点**：算法生成图丑 / 实物太大或太小 / 操作步骤超过 5 步

## 3. P2 · 「亲子手作宝妈」李姐

### 3.1 基础信息
| 项 | 内容 |
|---|---|
| 年龄 | 30~38 岁 |
| 性别 | 女 |
| 家庭 | 已婚，有 1 个 5~10 岁孩子 |
| 城市 | 一线~三线均有 |
| 月可支配收入 | 5000~15000 元（家庭决策权） |
| 常用 App | 微信（重度）、小红书、抖音、家校群 |

### 3.2 JTBD 精简映射

| JTBD 字段 | 内容 |
|---|---|
| Job Statement | 当周末有空，我想找一个安全的手作活动，以便和孩子一起做 |
| Functional Job | 用孩子的照片定制可参与的简单拼豆 |
| Emotional Job | 陪伴孩子的成就感 + 安心 |

### 3.3 行为画像
- 周末为孩子寻找"有教育意义的手作活动"
- 决策时**先关心安全**，再关心教育价值，最后关心价格
- 容易成为"妈妈群口碑传播节点"
- 在意作品的"成就感"，喜欢和孩子一起做并展示

### 3.4 核心需求与痛点

| 需求 | 痛点 | 产品如何回应 |
|---|---|---|
| 安全可靠的手作材料 | 担心三无产品有毒 | SGS 认证强制准入（关联 guihua.md §八） |
| 教孩子专注力 / 色彩认知 | 一般手作复杂度不可控 | 「萌宠 mini」档（≤ 8 色）适合儿童（关联 ADR-024） |
| 熨烫环节风险高 | 怕孩子被烫伤 | 包裹内安全卡 + 履约关怀（关联 ADR-017） |
| 作品要能展示给老师 / 朋友圈 | 标品图案孩子不感兴趣 | 用孩子的画/照片定制 |

### 3.5 用户原话
> *"做拼豆挺好的，但是熨斗那一步我都不敢让孩子靠近。"*  
> *"我就怕买的豆子是三无的，那种塑料烫了味道大。"*

### 3.6 关键决策点
- **进入路径**：妈妈群推荐 / 家校老师推荐 / 微信公众号
- **最关心**：安全 > 教育 > 趣味 > 价格
- **流失点**：没有看到 SGS 标识 / 安全警示不足 / 无法和孩子共同操作

## 4. P3 · 「硬核创作者」阿杰

### 4.1 基础信息
| 项 | 内容 |
|---|---|
| 年龄 | 18~30 岁 |
| 性别 | 男女均有，男性略多 |
| 身份 | 在校大学生 / 自由职业者 / 退休 / 宝妈兼职 |
| 时间富裕度 | 高（每天可投入 ≥ 2 小时） |
| 收入诉求 | 副业增收 500~3000 元/月 |

### 4.2 JTBD 精简映射

| JTBD 字段 | 内容 |
|---|---|
| Job Statement | 当我有空闲时间，我想把拼豆爱好变成副业 |
| Functional Job | 在平台接代拼单或卖原创图纸 |
| Emotional Job | 技术被认可的身份感 |

### 4.3 行为画像
- 已经是拼豆爱好者，会在小红书/B站发自己的作品
- 拼图技术 ≥ 1 年经验，能完成大尺寸（48×48 以上）
- 想从爱好变现，但没渠道
- 对图纸版权、稀有色号、专业工具有强烈兴趣

### 4.4 核心需求与痛点

| 需求 | 痛点 | 产品如何回应 |
|---|---|---|
| 技术变现 | 在闲鱼接单不安全、维权难 | 平台担保的代拼撮合（关联 ADR-006） |
| 稳定的图纸销售渠道 | 自己作品难以被发现 | UGC 社区 + 创作者激励（Phase 2） |
| 稀有色号收集 | 商城从来不卖 | PX 积分兑换非卖品（关联 ADR-007） |
| 创作身份认同 | 没有徽章/等级体现资历 | 多级徽章 + 大师认证（Phase 2） |

> ⛔ PX 兑换钩子 — MVP 砍除，推迟到 Phase 2 与 UGC 社区一起做  
> 取代方案：MVP 仅靠首单大礼包 + 老用户 9 折 + 实体卡券维持复购钩  
> 关联 ADR：ADR-018

### 4.5 用户原话
> *"我在小红书有几千粉丝，私信问我接不接代拼的特别多，但单独走支付宝转账太麻烦也不安全。"*  
> *"想要那种限量金属色，淘宝从来没卖过。"*

### 4.6 关键决策点
- **进入路径**：B 站/小红书内容 + 平台主动招募
- **最关心**：作品曝光 + 稳定佣金 + 身份认同
- **流失点**：抽佣比例太高（> 20%）/ 平台流量不公平 / 稀有色号永远抢不到

|---|---|

| 性别 | 男（占多） |

| 价格敏感度 | 极低（"贵点没事"） |

### 5.2 JTBD 精简映射

| JTBD 字段 | 内容 |

| Job Statement | 当临近重要纪念日，我想送个独一无二的礼物 |
| Functional Job | 买现成成品，最好平台代拼 |

### 5.3 核心需求

### 5.4 产品如何回应

- 代拼撮合（Phase 2 启用）

- 节日营销日历（情人节/纪念日打头阵）

### 5.5 用户原话
> *"明天结婚纪念日了，能不能帮我把结婚照做成拼豆？包装要好的。"*

## 6. P5 · 「线下店主」王老板（B 端 / Phase 2）

### 6.1 基础信息
| 项 | 内容 |
|---|---|
| 经营 | 商场内手作体验店 |
| 拼豆品类占比 | ≥ 60% 营收 |
| 痛点 | 新手顾客频繁问颜色和位置，店员陪同成本高 |
| 月营收 | 3~10 万 |

### 6.2 JTBD 精简映射

| JTBD 字段 | 内容 |
|---|---|
| Job Statement | 当顾客在店里犹豫颜色和位置时，我想让他们自助下单 |
| Functional Job | 扫码生成图纸 + 配料 + 落入私域 |
| Emotional Job | 店员效率提升 + 复购被锁住 |

### 6.3 核心需求
- 引流到店 + 减轻店员陪同负担
- 顾客自助生成图纸 + 自动配料
- 客流转化为长期复购（线下→线上）

### 6.4 产品如何回应
- 线下 SaaS（Phase 2 W9）
- 商家端图纸生成器
- 顾客扫码即落入私域

> 🅿️ Phase 2 占位  
> P5 B 端 SaaS 在 MVP 不启用，Phase 2 启用。当前文档保留画像与需求结构定义，仅作向前兼容。  
> 关联 ADR：ADR-012

## 8. 决策时的"问 Persona"工具

每次产品决策时，问自己：

> 「这个改动会让 **P1 小薇** 更愿意完成下单 + 更想发小红书吗？」

如果答案是"无所谓"或"会让她皱眉"，那这个改动应该被砍掉或改方案。  
P2~P4 仅作为兼容性约束（不要主动做坏），不作为立项依据：

> 「这个改动会让 **P2 李姐** 不放心吗？」（红线：安全 / SGS）  
> 「这个改动会让 **P3 阿杰** 觉得被平台薅了？」（红线：抽佣 / 流量公平）

## 10. 灵魂三句话锚点

> 拼豆产品灵魂三句话（关联 ADR-013）：
> 1. 零智商税
> 2. 把感情做成礼物
> 3. 在心流中找回自我
>
> 本文档关键设计点与三句话的对应关系如下，逐条接受未来重大改动的"反查"。

| # | 设计 / 决策点 | 对应灵魂 | 一句话理由（≤ 40 字） |
|---|---|---|---|
| 1 | MVP 单 Persona 聚焦 P1 | 零智商税 | 不再多目标对冲，决策语言最锐 |
| 2 | P1 Social Job：晒图收赞 | 把感情做成礼物 | 礼物先送给"未来在小红书的自己" |
| 3 | P1 Emotional Job：成就感 + 治愈感 | 在心流中找回自我 | 把"做手作"映射到情绪兑换 |
| 4 | P3 PX 钩子推迟到 Phase 2 | 零智商税 | 不给用户看不能用的余额 |
